# SEO content checklist

Use this for every new public page.

```text
[ ] Unique title
[ ] Unique meta description
[ ] Canonical URL on https://ammartariq.com
[ ] One clear H1
[ ] Logical headings after that
[ ] The page says something a recruiter or client can use
[ ] Internal links to a related project, service, or contact
[ ] Images have real dimensions and are not the LCP image if they are below the fold
[ ] Alt text describes the image
[ ] JSON-LD matches visible content
[ ] Open Graph title, description, URL, and image
[ ] Added to the sitemap only if it should be indexed
[ ] No accidental noindex
[ ] Not blocked by robots.txt
[ ] No staging, localhost, or example.com URLs
[ ] No invented metrics, clients, awards, or offices
[ ] Checked on a phone-width viewport
[ ] Title and canonical checked in the page source, not only the browser tab
```

Copy rules:

- Say Karachi, Pakistan when you say where Ammar is based.
- Remote work worldwide is remote work. It is not an office in another city.
- On-site outside Pakistan only when the employer provides relocation or visa support.
- Prefer the project’s real technologies over a generic “web developer” label.
- If a number is not already in the project record, do not add one.
